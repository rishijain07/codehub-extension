Questions, answered

A few things worth knowing.

Does CodeHub work with private GitHub repositories?

Yes. During GitHub authentication, CodeHub requests the repository scope needed to push to a public or private repository you choose.

Will re-solving a problem overwrite my existing solution?

No. Each problem has its own directory, and later submissions become new commits so your progress stays in Git history.

How does Codeforces synchronization work?

Add your Codeforces handle in the extension. CodeHub checks the public API in the background for newly accepted contest and practice submissions.

How does HackerRank synchronization work?

CodeHub syncs accepted public Practice/Prepare and anonymously public contest challenges. It reads the active editor and falls back from fullscreen URLs to the canonical problem page when difficulty is hidden. Hiring assessments, tests, and interview pages are excluded.

Is CodeHub free?

Yes. CodeHub is free to install from the official Chrome Web Store listing.
