Privacy & Security Architecture

Your code never touches our servers.
Because we don’t have any.

CodeHub is intentionally engineered without a backend server, telemetry, or remote database. All operations take place strictly inside your browser sandbox.

  • ✓ Direct Sandboxed Storage: Tokens are stored strictly in chrome.storage.local, completely isolated from any external web page or script.
  • ✓ Direct HTTPS Handshake: Browser communicates directly with api.github.com and the official Codeforces API without any intermediate proxy or middleware.
  • ✓ Instant Data Wipe: Uninstalling the extension wipes 100% of stored data. Or use the built-in "Reset Stats" feature anytime.

Frequently Asked Questions

Does CodeHub work with private GitHub repositories? ⌄

Yes, absolutely. During OAuth authentication you grant standard repository scope. CodeHub can push seamlessly to any repository you own — whether public or private.

Will it overwrite my existing solutions if I solve again? ⌄

No. Each problem gets its own designated directory with a README and code file. If you re-submit an optimized solution, CodeHub adds a new commit to your git history so your progress remains preserved.

How does Codeforces synchronization work? ⌄

Simply enter your Codeforces handle in the extension popup. CodeHub uses the public Codeforces API in the background to automatically check for newly accepted submissions from contests or problemset practice and commits them to your repository.

How do I install CodeHub? Is it free? ⌄

Yes, CodeHub is 100% free to use. You can install it with one click directly from the official Chrome Web Store listing.
