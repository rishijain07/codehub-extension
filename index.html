Frequently asked questions

Does CodeHub work with private GitHub repos? ⌄

Yes. During OAuth you grant repo scope. CodeHub can push to any repo you own — private or public — that you select in the setup flow.

Will it overwrite my existing solutions? ⌄

No. Each problem gets its own folder with README + code file. If a solution already exists, CodeHub creates a new commit without deleting history.

Is Codeforces sync automatic? ⌄

Yes. After you save your handle, CodeHub polls the public Codeforces API in the background and syncs newly accepted submissions.

How do I install it? Is it on the Chrome Web Store? ⌄

Yes — available now. Install directly from the Chrome Web Store listing (chromewebstore.google.com/detail/codehub/dgjlfbfaepcbokmgpicnngbdfckcloaf) as documented in README.md: Step 1. One click to add to Chrome — no manual zip, no Firefox version.
